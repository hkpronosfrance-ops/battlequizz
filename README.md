# battlequizz

Quiz interactif pour TikTok Live — overlay OBS, votes en chat (A/B/C/D), classement live, voix IA.

Stack : Next.js (Vercel) + Supabase (Postgres/Realtime/Storage) + bot Node.js (TikTok Live Connector, tourne en local via PM2).
